# ERCMed TV para Windows

Aplicativo auxiliar que abre o Globoplay no Microsoft Edge do segundo monitor e mantém o painel público de chamadas sobre a transmissão.

## Gerar o instalador

1. Execute `npm install` nesta pasta.
2. Execute `npm run dist`.
3. O instalador será criado na pasta `dist`.

Depois de instalado, o protocolo `ercmedtv://` é registrado no Windows. O botão **Iniciar ERCMed TV** do ERCMed envia os endereços autorizados ao aplicativo.
